## 2. 口径澄清（实施按此执行）

1. **基线锚点**（补 §2／§8）：任务基线一律取 `614bddd…`；本任务不依赖工作区其它改动，若开工时发现他人改动则记录并避开，不回滚。

3. **「生产非测试部分不变」的判定方法**（细化 §3／§8）：不比对文件总 SHA；对每个被改动的 `.rs` 逐文件剔除所有 `#[cfg(test)]` 修饰条目（含其上方紧邻注释）后比较剩余生产文本（`prod_blocks.py`）。该工具自检 3/3：提取非空、追加测试块不敏感、生产文本被改动必须检出。
4. **§5 指定项实名核对**：`p21_later_slot_reject_leaves_the_first_slot_unmoved`（`tests_each_consume.rs:1894`）、`e22_late_slot_rejection_leaves_no_partial_commit`（`tests_promote_group.rs:503`）、`b11_retry_rebuilds_factory_per_attempt_and_cleans_before_next`（`tests_v22_t02_repeat.rs:324`）、`b12_child_factory_registers_in_current_scope_and_exports_owned`（`:612`）、`c03_root_expectation_*`（`tests_v22_t03.rs:61/103`）、`x23a`～`x23d`（`tests/we_t06_pending.rs:331/378/494/582`）均存在并已列为强制保留项。
5. **UI 集合精简粒度**（§7）：按「每类契约留一代表 + 一整套对外正例 + 2 见证对照 + 独立消费者」重建清单：157 行 → **64 行**（62 主项 + 2 见证），夹具 382 → **63**。判定口径保持严格（错误码 + 允许集合 + 唯一锚点行 + 符号），并新增 `--self-test`（13 项：含「意外编译成功必须被拒绝」「无关错误码必须被拒绝」「错误位置/符号必须被严格判定拒绝」「伪装见证必须不成立」）。
6. **消费者**（§7）：新建 `tests/support/consumer/`（`roundkit` 重命名依赖 + `#[derive(Data)]` + 五种普通控制入口 + 16 槽 Root），`--locked` + 外置 `CARGO_TARGET_DIR`，不依赖也不改写 `docs/` 内既有消费者。
7. **旧入口失效声明**（§7 末段）：`docs/` 内各历史 `ui_check.py` 与其清单依赖被删除的夹具路径，本任务后**不再适用**；日常验证由 `tests/support/ui_check.py` 接替。旧脚本与旧矩阵继续作为 T07 时点历史证据，不回写、不改写、不重跑。
